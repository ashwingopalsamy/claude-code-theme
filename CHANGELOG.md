# Changelog

## 1.3.0
- **(No Bold)** twin for every flavor.
- 4 new flavors: **Midnight** (true-black OLED), **Dusk** (claude.ai dark), **Mono Dark** / **Mono Light** (focus mode) — 20 themes total.
- Claude Code chat: @-file chips are now clay and readable in every flavor, including High Contrast (#2).
- Brand (No Bold) themes now get the clay status bar and buttons like their bold twins.
- Coverage for 2026 VS Code surfaces: agent sessions, inline edits (next edit suggestions), SCM graph, terminal suggest icons, sticky scroll, gauges, markdown alerts.
- Published to Open VSX for Cursor, Windsurf and VSCodium (#3).
- New auto-generated screenshots; README rewritten; smaller VSIX (screenshots no longer bundled).

## 1.2.2
- Brand variants: fixed text color on the clay status bar, buttons and badges in dark and light modes.

## 1.2.1
- Brand variants: clay status bar, buttons and badges now use mode-aware surface and text colors.

## 1.2.0
- New **Dark Brand** and **Light Brand** variants with Claude-orange chrome on the status bar and buttons.

## 1.1.0
- Terminal and ANSI palette finalized for Claude Code's terminal output.
- Wider workbench coverage: chat and inline chat, merge editor, notebooks, testing, inlay hints, ghost text.

## 1.0.1
- Maintenance release.

## 1.0.0
- Initial release: Claude-inspired Dark and Light themes, each with a High Contrast variant.
- Syntax highlighting for JS/TS, Go, Python, Java, Rust, HTML/CSS, JSON/YAML, Markdown and SQL.
